Do I need an account?

No. TrackHit has no sign-in. There is no password to recover.

Where is my data?

On this iPhone. Settings → Export saves a JSON file you can keep in Files or AirDrop to another device. Settings → Import loads it. Settings → Delete all data wipes workouts, routines, and custom exercises on this phone.

I switched phones

On the old phone, Export. On the new phone, install TrackHit, then Import. Choose Replace to start from that file, or Merge to keep anything already logged.

Rest notifications

Allow notifications when iOS asks, or enable them later in iOS Settings → TrackHit. Alerts are scheduled on the device. They will not arrive if the app was never granted permission, or if Focus is silencing them.

Demo data

Settings → Mock data shows a sample log so you can feel the graphs. Turn it off and your real (or empty) history returns. Mock data is not saved as yours.

Something looks wrong

Force-quit and reopen. If a workout is stuck, finish or cancel it. If graphs still show a previous pointer, leave the Profile tab and come back. Still stuck? Email a screenshot and your iOS version.
