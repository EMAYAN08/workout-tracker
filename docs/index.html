What it is

The log. Nothing else.

TrackHit is built to disappear once the set starts. No feed. No streak guilt from a server. No one watching.

01

Routines

Build Push / Pull / Legs, Upper Lower, or a custom split. Drag to reorder. Start a session in one tap.

02

The session

Log weight and reps on a custom keypad. Rest timer on the lock screen. A quiet PR badge when you earn it.

03

The picture

Consistency map, strength radar, volume and time. Share a day as an image. Export a JSON backup when you switch phones.

Privacy

Nothing leaves the phone.

No accounts

Open the app and lift. There is no sign-in with Apple or Google because there is nothing to sign in to.

No server

Workouts, routines, and custom exercises live in on-device storage. We do not run a backend for this app.

No tracking

No analytics, ads, crash reporters, or advertising ID. Rest alerts are scheduled locally.

You own the file

Export a JSON backup, import it on another phone, or wipe everything in Settings. Share sheets go through iOS — we never upload the file.
